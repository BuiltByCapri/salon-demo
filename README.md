# Casa Luz salon demo

A sample salon site and separate booking page, for showing salon owners what Built by Capri can build. Casa Luz is fictional.

- `index.html`: the site, English first with a Spanish switch.
- `booking.html` + `booking.js`: booking on its own page. Guests, a service and stylist per guest, a time when the whole group can be seen, then a deposit. Nothing is charged.
- `salon.js`: the salon's data. Stylists, their weekly schedules and services, prices and hours. Swap this per salon.
- `img/`: team portraits generated in Canva.
